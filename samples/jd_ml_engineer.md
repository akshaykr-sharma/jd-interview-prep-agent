# Senior Machine Learning Engineer

**Location:** Bengaluru (hybrid) · **Team:** Personalisation Platform

## About the role

We are looking for a Senior ML Engineer to own the models that rank content for 40M monthly users. You will take models from notebook to production, keep them healthy, and work closely with product managers and data engineers.

## What you will do

- Design, train and ship ranking and recommendation models (gradient boosted trees and deep learning)
- Build feature pipelines in PySpark on Databricks and maintain the feature store
- Run offline evaluation and online A/B tests, and explain results to non-technical stakeholders
- Deploy models as low-latency services with FastAPI and Docker on Kubernetes
- Set up monitoring for data drift and model performance, with automated retraining in Airflow
- Mentor two junior engineers and review their code

## What you need

- 5+ years of Python in production
- Strong ML fundamentals: bias/variance, regularisation, evaluation metrics (AUC, NDCG, precision@k)
- Hands-on with XGBoost or LightGBM, and PyTorch
- SQL and PySpark at scale
- Experience with MLflow or a similar experiment tracking tool
- AWS (S3, SageMaker or EKS)
- CI/CD with GitHub Actions

## Nice to have

- Experience with LLMs, embeddings and vector search
- Causal inference or uplift modelling
- Contributions to open source
