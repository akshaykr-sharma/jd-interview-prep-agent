# GenAI Engineer

**Team:** Applied AI · Bengaluru

You'll build the LLM features inside our customer support product: retrieval-augmented answers, agents that take actions in our ticketing system, and the evaluation setup that tells us whether a change made things better or worse.

## You will

- Build RAG pipelines: chunking, embeddings, hybrid search over a vector database (pgvector or Qdrant), reranking
- Build multi-step agents with LangGraph, including tool calling and human approval steps
- Own evaluation: golden datasets, LLM-as-judge, regression tests in CI, tracing with LangSmith
- Optimise cost and latency: prompt caching, model routing, streaming responses
- Serve everything behind FastAPI with async Python
- Work with security on prompt injection defences and PII redaction

## You have

- 3+ years of backend Python
- Shipped at least one LLM feature to real users
- Prompt engineering and structured output (JSON schema / function calling)
- Solid understanding of transformers, tokenisation and context windows
- Docker and one cloud provider (AWS or GCP)

## Bonus

- Fine-tuning with LoRA / PEFT
- Running open models locally (Ollama, vLLM)
- Experience with Kubernetes
