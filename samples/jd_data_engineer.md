# Data Engineer II

**Team:** Analytics Platform · Remote (India)

We move about 2 TB a day from product databases and third-party APIs into our lakehouse. You'll build and run those pipelines and make the data trustworthy for analysts and data scientists.

## Responsibilities

- Build batch and streaming pipelines with Apache Spark and Kafka
- Model data in the warehouse using dbt and dimensional modelling (star schemas, slowly changing dimensions)
- Orchestrate jobs with Airflow and own their SLAs
- Write data quality checks (Great Expectations or similar) and handle incidents
- Tune Spark jobs and Snowflake queries for cost and speed
- Work with analysts to turn vague questions into clear data contracts

## Requirements

- 3+ years in data engineering
- Expert SQL, including window functions and query plans
- Python for pipeline code and testing (pytest)
- Spark (PySpark or Scala) and Kafka
- Snowflake or BigQuery
- Git and Terraform for infrastructure as code

## Good to have

- Delta Lake or Apache Iceberg
- Experience with CDC tools such as Debezium
- Basic knowledge of GDPR and data privacy
